# Karl logo (monoline)

A chat bubble and a lowercase k, drawn with one stroke weight on a 1024 grid, with round caps and round joins.

| File | Use |
|---|---|
| `karl-mark.svg` | App icon: white mark on a Carolina blue rounded tile. 32px and up. |
| `karl-favicon.svg` | Same mark with a heavier stroke (96 instead of 60). Use under 32px, including favicons. |
| `karl-mark-mono.svg` | Mark only, colored with `currentColor`. For lockups and to tint over any background. |
| `tokens.css` | Colors, fonts, type sizes. |

**Lockup:** mark at about 1.1× the wordmark's cap height, then "karl" in Inter Display Semibold, lowercase, tracking -0.045em. The gap between them is half the mark's width.

**Colors:** Carolina blue `#4B9CD3`, deep `#2F7DB5`, navy `#0F1B2D`, white. Green `#5BE08F` and red `#FF6B6B` are only for safety moments.

**Don'ts:** don't fill the bubble, change the stroke weight between the bubble and the k, add gradients to the flat mark, or put the blue mark on a mid-tone background.

The whole mark sits inside the central circle, so iMessage's circular avatar crop doesn't clip it.
